# K-Agent 快速使用指南

本指南将带你快速上手 K-Agent 故事创作系统，体验完整的创作流程。

## 🚀 一分钟快速开始

### 第一步：启动服务

1. **启动后端**
```bash
# 在项目根目录
source venv/bin/activate  # 激活虚拟环境
python3 app.py
```
后端将在 `http://localhost:8080` 运行

2. **启动前端**
```bash
# 新开一个终端
cd frontend
npm run dev
```
前端将在 `http://localhost:5173` 运行

### 第二步：开始创作

在浏览器中打开 `http://localhost:5173`，你会看到导航菜单：
- 🌍 世界观生成
- 👤 人物创建
- 🕸️ 人物关系网
- 📜 核心故事线
- 📦 缓存管理

## 📖 完整创作流程示例

让我们创建一个仙侠世界的完整故事！

### 步骤 1：生成世界观

1. 点击 **"🌍 世界观生成"**
2. 填写信息：
   - 世界名称：`玄灵界`
   - 题材：`仙侠`
   - 基础设定：`高魔世界，修真门派林立`
3. 点击 **"生成完整世界"**（一键生成所有内容）
4. 等待约 30-60 秒，你将看到：
   - 世界标题和基础设定
   - 地理环境描述
   - 社会结构介绍
   - 历史背景
   - 主要势力列表

### 步骤 2：创建主角

1. 点击 **"👤 人物创建"**
2. 填写信息：
   - 关联世界观：选择刚才生成的 `玄灵界`
   - 人物姓名：`李云飞`
   - 角色定位：`主角`
   - 性格特质：`坚韧不拔、重情重义、有正义感`
3. 点击 **"生成人物"**
4. 查看生成的人物卡片，包含：
   - 人物头像和基本信息
   - 外貌描述
   - 性格特质
   - 背景故事
   - 能力技能
   - 完整的人生经历时间线

### 步骤 3：创建反派角色

1. 在人物创建页面，继续填写：
   - 关联世界观：`玄灵界`
   - 人物姓名：`血魔老祖`
   - 角色定位：`反派`
   - 性格特质：`阴险狡诈、野心勃勃、为达目的不择手段`
2. 点击 **"生成人物"**

### 步骤 4：生成核心故事线

1. 点击 **"📜 核心故事线"**
2. 填写信息：
   - 世界观：选择 `玄灵界`
   - 故事主题：`李云飞从一个普通少年成长为修真界传奇，对抗血魔老祖拯救世界`
   - 选择人物：勾选 `李云飞` 和 `血魔老祖`
3. 点击 **"生成核心故事线"**
4. 查看时间线式的故事展示：
   - 故事标题和主题
   - 按时间顺序排列的关键事件
   - 每个事件包含地点、描述、关键人物和重要性

### 步骤 5：查看和管理缓存

1. 点击 **"📦 缓存管理"**
2. 你可以：
   - 按分类查看所有生成内容
   - 搜索特定内容
   - 查看详细信息
   - 删除不需要的内容
   - 清空所有缓存

## 🎯 实用技巧

### 技巧 1：复用已有内容

- 在生成人物时，选择已有的世界观，可以让人物更符合世界观设定
- 在生成故事线时，从缓存中选择人物，确保故事连贯性

### 技巧 2：分步生成 vs 一键生成

- **分步生成**：先生成世界观，再创建人物，最后编写故事线，适合精细控制
- **一键生成**：在世界观页面点击"生成完整世界"，快速获得完整设定

### 技巧 3：使用缓存提高效率

- 所有生成的内容都会自动保存到缓存
- 可以随时在缓存页面查看和复用
- 可以删除不满意的内容重新生成

## 💡 常见问题解答

### Q: 生成需要多长时间？

A: 取决于内容复杂度和 AI 模型速度：
- 简单世界观：20-30 秒
- 完整世界：60-90 秒
- 人物：15-30 秒
- 故事线：30-60 秒

### Q: 可以修改生成的内容吗？

A: 当前版本暂不支持直接编辑，但你可以：
- 重新生成并覆盖
- 在缓存中删除后重新生成
- 复制内容到外部编辑器修改

### Q: 生成的内容保存在哪里？

A: 所有内容保存在项目根目录的 `cache/cache.json` 文件中，可以随时备份或迁移。

### Q: 可以使用中文输入吗？

A: 完全可以！系统对中文支持很好，所有界面和生成内容都是中文的。

## 🔧 进阶用法

### 使用火山引擎方舟

如果你有火山引擎方舟的 API，可以在 `.env` 文件中配置：

```
ARK_API_KEY=your_api_key
ARK_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
ARK_MODEL=ep-your-endpoint-id
```

### 自定义提示词

在 `app.py` 中可以找到各个工具的提示词模板，你可以根据需要修改它们来获得不同风格的生成结果。
